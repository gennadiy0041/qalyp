# Qalyp — ИИ-нормоконтроль студенческих работ по методичке вуза

**Рабочая версия без регистрации:** https://qalyp-web-production.up.railway.app

Qalyp проверяет курсовые и дипломные работы (.docx) по методичке конкретного вуза Казахстана.

**ИИ читает, код измеряет, решает человек.**

1. **Методичка → правила (ИИ).** Вуз загружает свою методичку. Claude выписывает из неё все требования к оформлению — у каждого правила дословная цитата и пункт. Программа находит цитату в тексте методички и проверяет значение по реестру допустимых диапазонов (`shared/code-params.json`). Нормоконтролёр утверждает профиль.
2. **Оформление (код).** В браузере код разбирает .docx: поля по всем разделам, шрифт, кегль, интервал, отступ, выравнивание, заголовки, подписи рисунков и таблиц (в том числе казахские «1-кесте», «Сурет 1»), нумерация страниц, список источников и ссылки в тексте. Исправленный .docx можно скачать.
3. **Смысл и источники (ИИ + открытые базы).** Claude проверяет введение и заключение (цель, задачи, объект, предмет, методы; отвечает ли заключение на задачи) — каждое «найдено» подтверждается цитатой. Записи списка источников сверяются с Crossref, OpenAlex, old.adilet.zan.kz и адресами сайтов; ИИ отмечает признаки в самой записи. Итог для человека — «Высокий риск — проверьте вручную», а не «выдуман».
4. **Решение (человек).** В режиме нормоконтролёра по каждому замечанию — «подтверждаю» или «не согласен»; протокол сохраняется в PDF.

**Готовые профили вузов (ИИ, заранее).** В библиотеке — правила из 7 открытых методичек вузов Казахстана, собранные тем же путём, что и кнопка «Собрать правила (ИИ)» (`eval/build-library.mjs` → `public/library/`). Профиль открывается на экране подтверждения с цитатами; применяет его человек. Вузами эти профили не утверждены — так и написано в интерфейсе. Новый вуз = одна методичка.

**Проверка группы (код).** Нормоконтролёр выбирает до 60 работ .docx сразу. Код проверяет их по очереди в браузере по выбранному профилю, без ИИ и без отправки на сервер. Итог — таблица с баллом, ошибками и главными замечаниями, самые частые нарушения в группе и CSV для Excel; любую проверенную работу можно открыть в полном отчёте.

## Данные

- Файл работы разбирается в браузере и на сервер не отправляется.
- На сервер уходят только введение, заключение, список источников и текст методички. ФИО с титульного листа, e-mail, телефоны и 12-значные номера вырезаются до отправки; сервер повторяет очистку.
- Перед первой ИИ-проверкой пользователь видит, что уйдёт в Claude (Anthropic, США), и подтверждает.
- Сервер не хранит тексты и не пишет их в журнал.

## Устройство

| Часть | Где |
|---|---|
| Страница (одна, без фреймворков) | `src/index.html` + `src/js/*.js` → `npm run build` → `public/index.html` |
| Проверка группы | `src/js/45-batch.js` |
| Библиотека готовых профилей | `src/js/65-library.js`, `public/library/`, сборка — `eval/build-library.mjs` |
| Сервер (Express) | `server/index.js` |
| Вызовы Claude, промпты, проверка ответов | `server/ai.js`, `server/prompts.js` |
| Сверка источников без ИИ | `server/refs.js`, `server/refparse.js` |
| Лимиты, кеш, обезличивание | `server/limits.js`, `server/cache.js`, `server/redact.js` |
| Контракты между частями | `docs/ARCHITECTURE.md` |
| Формула балла | `docs/SCORING.md` |
| Замеры качества ИИ | `eval/` — см. `eval/README.md` |

Модель: Claude Opus 5.5 (`claude-opus-5-5`) через Anthropic API, ответ строго по JSON-схеме (structured outputs), серверный резерв при отказе модели.

## Запуск

```bash
npm install
cp .env.example .env   # вписать ANTHROPIC_API_KEY
npm run build
node --env-file=.env server/index.js
```

Без ключа проверка оформления работает, ИИ-кнопки честно выключены.

## Тесты

```bash
npm test
```

Регрессия на встроенном примере — `tests/sample.test.mjs`; разбор .docx — `tests/parse.test.mjs`; автоисправление — `tests/fix.test.mjs`; сервер на поддельном API Anthropic — `tests/server.test.mjs`; сверка источников на записанных ответах баз — `tests/refs.test.mjs`; интерфейс — `tests/ui.test.mjs`; проверка группы — `tests/batch.test.mjs`; библиотека профилей — `tests/library.test.mjs`; сквозной путь (настоящий сервер, поддельный Anthropic, записанные ответы баз) — `tests/e2e.test.mjs`.

## 1. Методичка → правила (`eval/method.mjs`)

**Данные.** 7 открытых методичек вузов Казахстана с официальных сайтов (2020–2025): AlmaU, КазНАИ им. Жургенова, КарУ Казпотребсоюза, Костанайский региональный университет, Университет Maqsut Narikbayev (на казахском), Satbayev University (на английском), Актюбинский региональный университет им. Жубанова. Методичка КУАМ — [после получения].

**Эталон.** Две независимые разметки каждой методички целиком (все требования к оформлению, у каждого — дословная цитата и пункт), затем сведение: правило попадает в эталон, только если цитата найдена в тексте. Итого 1 108 правил. Значения параметров, которые проверяет код (80 значений), проверил человек: [кто, когда, сколько исправлено].

**Что считаем — без нейросети-судьи:**
- *Параметры оформления* (поля, шрифт, кегль, интервал, отступ, выравнивание, номер страницы, требования к источникам): значение ИИ совпало с эталоном — верно; ИИ дал значение, которого в эталоне нет или оно другое — ложное; в эталоне есть, ИИ не дал — пропуск. Точность = верные / (верные + ложные), полнота = верные / (верные + пропуски).
- *Все правила*: правило эталона найдено, если цитата ИИ пересекается с его цитатой не меньше чем на 50% (по тройкам слов). Отдельно — доля правил ИИ, чьей цитаты нет в тексте методички («выдуманные цитаты»).

## 2. Выдуманные источники (`eval/refs.mjs`)

**Данные.** 185 библиографических записей: 87 настоящих (русские, казахские, английские книги и статьи из опубликованных работ казахстанских авторов; законы РК и сайты госорганов) — каждая подтверждена по каталогу, DOI или adilet.zan.kz; 98 выдуманных — полностью вымышленные, «химеры» (настоящий автор или журнал + несуществующая работа), несуществующие акты и страницы, и 18 реальных выдуманных ссылок, которые нашли в публикациях о галлюцинациях языковых моделей. Каждую метку перепроверил второй исполнитель.

**Что считаем.** «Тревога» = статус «Высокий риск — проверьте вручную». Точность — доля выдуманных среди тревог; полнота — доля выдуманных, получивших тревогу; ложные тревоги — доля настоящих, получивших тревогу. Отдельно: только базы, только ИИ, вместе.
